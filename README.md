# ORION

Modular Autonomous Formula-Style Vehicle Platform

## Overview

ORION is a Formula-style engineering platform designed to explore the intersection of:

* Mechanical Engineering
* Robotics
* Embedded Systems
* Artificial Intelligence
* Autonomous Vehicles
* Additive Manufacturing

The project is being developed from the ground up using SolidWorks, 3D printing, custom electronics integration, telemetry systems, computer vision, and future autonomous driving capabilities.

Unlike a traditional RC vehicle, ORION is designed as a scalable engineering platform that evolves through multiple development stages, from manual remote control operation to AI-assisted and fully autonomous driving.

---

## Project Objectives

### Mechanical Engineering

* Design a complete Formula-style vehicle in SolidWorks
* Develop a modular chassis architecture
* Create manufacturing-ready CAD assemblies
* Produce technical drawings and engineering documentation

### Manufacturing

* Manufacture structural components using 3D printing
* Assemble a complete rolling chassis
* Validate modular assembly concepts

### Embedded Systems

* Integrate Raspberry Pi based computing
* Implement telemetry and sensor systems
* Develop onboard data acquisition

### Artificial Intelligence

* Computer Vision
* Lane Following
* Object Detection
* Autonomous Navigation
* AI Driver Development

---

## Vehicle Architecture

ORION is divided into three major removable modules:

### Front Module

* Nose structure
* Steering system
* Front suspension
* Sensor integration

### Central Module

* Cockpit
* Battery compartment
* Main electronics
* Computing hardware

### Rear Module

* Motor
* ESC
* Powertrain
* Rear wing
* Future DRS integration

This architecture allows rapid iteration and subsystem upgrades without redesigning the entire vehicle.
